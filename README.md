# 公共管理学术图例合集（Public Administration Academic Figures Collection）

> 面向中文公共管理（行政管理、公共政策、数字治理、基层治理等方向）研究者的**学术图例 / 论文题录合集**。
> 灵感来自微信公众号「赫尔墨斯的公共管理百宝袋」的【学术图例】与【百宝袋】系列——即把 C 刊论文中的**分析框架图、机制图、技术路线图**按主题汇编，并定期追踪最新发表论文。

## 这个仓库收什么

1. **【学术图例】系列索引**：按主题分类的图例汇编清单（基层治理、数字治理、协同治理、社区治理、研究方法等），标注期数、日期、来源链接与所引论文。
2. **【百宝袋】论文追踪题录**：每期推荐的最新论文书目（作者、标题、期刊、年卷期）。
3. **期刊导航**：公共管理 CSSCI 期刊与英文顶刊目录。
4. **资源清单**：GitHub 相关仓库、公众号、数据库与开放获取渠道。

## 版权说明（重要）

- 本仓库**只收录论文题录（书目信息）、主题分类与链接**，不转载任何论文全文、图片或公众号排版内容。
- 学术图例中的图片版权归原作者与期刊所有，请通过 CNKI 等正规渠道获取原文。
- 「赫尔墨斯的公共管理百宝袋」公众号的题录汇编仅供学术交流索引使用；该公众号曾因内容标注问题与其他账号产生争议，本仓库不代表对其运营方式的背书。

## 如何贡献

欢迎提 PR / Issue：
- 补充新的【学术图例】期数（公众号历史消息中还有更多期）；

- 推荐其他同类公众号或 GitHub 仓库（见 resources.md）；
- 把 papers.csv 扩展成更完整的结构化数据库。
