# 公共管理学术图例合集（Public Administration Academic Figures Collection）

> 面向中文公共管理（行政管理、公共政策、数字治理、基层治理等方向）研究者的**学术图例 / 论文题录合集**。
> 灵感来自微信公众号「赫尔墨斯的公共管理百宝袋」的【学术图例】与【百宝袋】系列——即把 C 刊论文中的**分析框架图、机制图、技术路线图**按主题汇编，并定期追踪最新发表论文。
> 但**来源不局限于一个号**：本仓库同时收录其他公众号、期刊专栏、年度报告与镜像站点上的同类汇编（见 sources.md，已盘点 4 大类 10+ 个国内外来源）。

## 这个仓库收什么

1. **gallery/ 画廊**：图例内嵌展示页（本仓库核心价值）；
2. **【学术图例】系列索引**：按主题分类的期数清单（index/）；
3. **【百宝袋】论文追踪题录**：每期最新论文书目（digest/ + data/papers.csv）；
4. **全网同类来源地图**：其他做论文推荐/框架图汇编的公众号、期刊专栏、年度报告（sources.md）；
5. **期刊导航与资源清单**：journals.md、resources.md。

## 版权说明（重要）

- 画廊中的**图片版权归原作者与期刊所有**，仅作学术索引与非商业展示；如有侵权请联系删除。
- 题录（书目信息）、主题分类与链接的汇编遵循学术引用规范；写论文请引用原始期刊论文，而非本仓库。
- 「赫尔墨斯的公共管理百宝袋」公众号的题录汇编仅供学术交流索引使用；该公众号曾因内容标注问题与其他账号产生争议，本仓库不代表对其运营方式的背书。
